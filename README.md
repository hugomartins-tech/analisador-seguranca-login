# analisador-seguranca-login
Analisador de segurança desenvolvido em Python para avaliar tentativas de login e identificar situações que podem indicar um comportamento suspeito.

Analisador de Segurança de Login

Sobre o projeto

Este projeto foi desenvolvido em Python com o objetivo de praticar conceitos básicos de programação e Segurança da Informação.

O programa recebe o nome de um usuário e a quantidade de tentativas de login informadas, realizando uma análise simples com base nesses dados.

Funcionalidades

 Receber o nome do usuário.
 Informar a quantidade de tentativas de login.
 Identificar números elevados de tentativas.
 Exibir alertas de possíveis comportamentos suspeitos.
 Validar os dados informados pelo usuário.

Tecnologias utilizadas

 Python 3
 Estruturas condicionais ("if", "elif" e "else")
 Estruturas de repetição ("while")
 Tratamento de exceções ("try" e "except")

Como executar

1. Instale o Python 3.
2. Baixe ou clone este repositório.
3. Execute o arquivo "analisador.py" em um ambiente Python.

Objetivo de aprendizagem

Praticar lógica de programação, validação de dados e conceitos introdutórios de Segurança da Informação.

Limitações

Este é um projeto educacional. A análise é baseada nos dados informados manualmente pelo usuário e não realiza monitoramento de sistemas ou detecção real de ataques.
